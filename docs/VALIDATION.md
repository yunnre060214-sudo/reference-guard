### 新增覆盖

- DOI 规范化、保留后缀标点、拒绝歧义 URL、429 与有限退避、网络与 HTTP 协议故障重试、登记机构回退、双 404 与部分访问失败区分。
- 正缓存、原抓取时间、大小/年龄/摘要/身份检查、离线不联网、过期记录不被当作现查证据、批次重复查询合并且保留输入数量。
- 复核摘要绑定取舍、证据、重复映射、主代理 ID 和排序；结构错误、非有限 JSON、重复 JSON 键、空白 ID、非法来源 URL 均被阻断。
- 原始 ID/原文序列指纹与数量一致性；最终文件字节检查、路径越界阻断；重复映射只能指向已保留条目。
- 初始化保留多行原文、字段比对与多出版日期提示、共享 DOI 仅作重复候选、冲突登记记录不按顺序择一、无 DOI 文献保留。
- 精确文本导出、完整复核与证据保留、部分交付显式控制、既存输出保护、历史问题结构检查与失败后恢复。
- APA 排序与原始 ID 追踪、UTF-8 BOM、非法日期/姓名/访问 URL 拒绝和有效闰日。

### 独立发现与修复

独立子代理发现并实际复现：初始化后漏项仍可能放行；非法 original_issues 导致导出中断并留下目录；IncompleteRead/BadStatusLine 中断 DOI 批次；带 BOM 的 CSL 无法渲染。修复后，独立复验确认漏项/改原文/改 ID 被 check 与 export 阻断，四类非法历史问题被阻断且修正后可在同路径重跑，HTTP 故障按设置重试且不影响后续输入，带 BOM 的 CSL 在三种内置格式下均可运行。

这次独立工作是代码维护和工具行为验证，没有把它冒称为新的真实文献全量核验。
