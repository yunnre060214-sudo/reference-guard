# 格式输出

## 确定适用规范

用户/机构/期刊明确给出的格式与模板作为本次目标；记录名称、版本及可核对的规范来源。没有明确要求就询问，用户明确无要求才采用 GB/T 7714—2025。不能把旧版样例改个版本号视为新版规范，也不能把文献表中的混合格式当作已确定的目标。

默认 GB/T 7714—2025 文献表使用顺序编码样式，按输入文献次序生成列表标签；它们只是文献表的排列，本 skill 不读取或修正文内引用次序。用户明确要求其他文献表组织方式时采用相应规范。每条保留原始 ID 到输出标签的映射。

## 可重复生成

内置固定版本 CSL 样式：`gbt2025`、`apa7`、`ieee`。先把已核实的作品字段转换为 CSL-JSON，保留记录中的题名、姓名、文种与出版版本信息；区分出版日期、在线日期和实际引用日期。

```sh
node <skill目录>/scripts/format_bibliography.cjs --style gbt2025 --input items.json --output rendered.json
```

`items.json` 是 CSL-JSON 条目数组。工具输出文献表文本、HTML、布局参数、稳定 ID、固定样式摘要、提示与必要的格式转换记录；结果是候选稿，不是核验结论。逐项处理 `warnings`，它不覆盖所有必备字段检查。APA 等要求的斜体和悬挂缩进应在最终载体中保留，纯文本输出不能证明这些排版已实现。不要在渲染后用模型自由重写字段、替换标点或嵌入说明链接。

GB/T 输入中的 `report` 默认表示独立报告，不能仅凭 `publisher` 推断出版形态。报告带出版者信息时，先从来源确定形态，再明确设置扩展字段 `publication-form` 为 `standalone` 或 `book`。独立报告按 8.8.3 输出已知的发布日期；图书形态按 8.8.1 转用图书规则，显示出版年。原始完整日期和出版者信息保留在输入与证据台账中；工具记录用于目标格式的字段转换。期刊形态或书中析出的报告要按实际形态及对应条款另外映射，不能硬套这两个选项。

引用日期只能来自实际访问，不作为出版年的替代。确有来源支持估计出版年时，`issued` 的 `circa: true` 保留估计标记；没有估计依据不得设置它。DOI 存在但未提供访问路径时，工具会提示补核 `URL`，不会伪造一个已访问的链接。

其他格式可提供独立 CSL 文件：`--style-file <文件>`。先核对它与用户指定规范的一致性。学校自定义细则需要按具体细则调整，不能声称内置样式覆盖所有变体。没有 Node 时优先使用已可用的 CSL 工具；手工排版必须依据可查阅的目标规范，仍接受完整独立复核。规范本身不可核实时，明确格式尚未核实。

命令找不到 Node 时，先查当前环境已经提供的运行时；桌面环境若提供 `load_workspace_dependencies`，使用它返回的实际可执行文件路径。不要把某台电脑的路径写入 skill，也不因命令暂不可用擅自安装依赖。

## GB/T 7714—2025 核对依据

[国家标准官方记录](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C6CE52E55AC09B9C79A20AEA77CEDD14)用于确认版本与状态；具体条款见[高校期刊公开的标准扫描文本](https://www2.abc.edu.cn/xbbjb/upload/2026-01/26012010262341.pdf)。只访问链接，不随 skill 重新分发标准全文。

核对定位：第 5—6 章的文字与符号；7.1 的姓名与多人责任者；7.5—7.9 的日期、出版信息、定位信息、访问路径与永久标识符；第 8 章按类型列出的必备/有则必备/电子资源必备字段；附录 A 的类型及载体代码。

重点查：不要机械沿用旧版全大写西文姓氏；不要把真实文章编号拼成页码；预印本用对应的 PP 类型，数据集用 DS；不能因从网站访问就把所有作品都当作网页。DOI 链接的字段组合按 7.8—7.9 校对，避免把“已知 DOI”误当成与所选作品匹配。格式允许省略的字段可以省略；缺失的必备信息明确待补，不靠估计凑齐。

CSL 是实现而非标准原文。子代理还要对照具体类型的规范独立检查。内置 GB/T 样式已按实际复现的问题做三处局部修补，见 `assets/styles/gbt2025-patches.md`；不能把它称作未经修改的上游文件。来源、原始与本地摘要记录在 `assets/manifest.json`；第三方授权说明在 `assets/THIRD_PARTY_NOTICES.md`。

其他规范入口：[APA 参考文献指南](https://apastyle.apa.org/style-grammar-guidelines/references)、[IEEE Author Center 的 Reference Guide 入口](https://journals.ieeeauthorcenter.ieee.org/your-role-in-article-production/ieee-editorial-style-manual/)。打不开规范时报告限制，不把文件名或样式引擎运行成功当作格式已经确认。
