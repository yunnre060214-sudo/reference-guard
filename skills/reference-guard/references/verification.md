# 真实性与信息核查

## 判定对象

核实的是**同一作品、同一出版版本**，不是“作者/期刊/DOI 分别是真的”。题名、责任者、载体、日期、卷期、页码或文章编号、版本、DOI/其他标识符必须相互对应。预印本、会议版、期刊版、再版、译本各自保留出版身份，不能拼接字段。

## 实际查阅

- 优先期刊、出版社、会议论文集、发布机构、机构仓储的作品记录或原文件。Crossref、DataCite、PubMed、可信文献数据库、图书馆目录可用于定位或交叉核查；中文文献使用已可访问的期刊官网、知网、万方、机构库等记录。
- 用题名检索，结合责任者/年份区分同名作品；有 DOI 时同时核对其实际所指作品。仅书目记录能确认所需字段时，不强求付费全文；需要确认版本、题名或缺失字段时查看原件。
- 搜索摘要、AI 回答、他人文献表、下载文件名只作线索。实际打开可定位的记录，保存 URL 或本地文件定位及核查位置。来源受限、OCR 有疑点或字段冲突时保留不确定性。
- 可信记录相互冲突时查出版版本、原文件或更正记录。不能按多数票或“哪个值更像真的”填入；仍无法消除身份歧义就询问用户。
- 未锁版本号的链接要实际核对其所指版本，记录原链接与最终定位。首发日期不是用户指定首版的证据；不能为了使日期看起来一致而改指另一版本。原链接能明确定位的版本予以保留，仍不能确定拟引身份时询问用户。

每条保留：`id`、`original`、作品/版本身份、实际输出字段及其来源/位置、访问情况、差异、未解决问题、候选修正版。不存在或不适用的卷期、页码、DOI 与“未找到该字段”分开记录。只需要证实最终采用的字段，不能把可合法省略的字段缺失当作作品虚假。

## 可作的结论

| 证据 | 结论与处理 |
|---|---|
| 可信记录可定位同一作品，输出字段已核实 | 已核实；可进入格式生成和独立复核 |
| 同一作品已明确，但原条目字段有错误 | 报告具体差异，按证据修正 |
| DOI/题名等指向不同作品，原意仍不明 | 身份待确认；列明冲突并询问用户 |
| 搜索未找到匹配记录 | 未找到可信匹配记录；说明检索范围，不推定绝对不存在 |
| 来源无法访问或必要信息无法确认 | 无法核实；报告访问或信息限制 |

错误的 DOI 可以确定为错配；这不自动证明整篇文献不存在。只有能直接证实的事实才作确定表述。不得把无法核实条目偷偷替换为主题相近的真文献，也不据此改变论文的引用选择。

## DOI 工具

有大量 DOI 时可运行：

```sh
python3 <skill目录>/scripts/doi_metadata.py 10.1038/s41586-021-03819-2
```

工具只读取公开 Crossref/DataCite 元数据，保留原字段和日期种类，不自动选择出版年或替某条引用判真伪。`record_found` 只表示注册记录可读；仍须比对题名、责任者和出版版本。`not_found_in_registries` 只表示在所查询的公共接口未取到记录；其他渠道与非公开注册状态仍可能存在。网络错误是 `access_failed`。

工具不覆盖无 DOI 文献，也不代替实际打开出版社/机构记录。接口失败时使用其他已可访问的权威来源；不要为了工具返回空值而删除已被其他证据核实的作品。

接口依据：[Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)、[DataCite 单条 DOI 查询](https://support.datacite.org/docs/api-get-doi)、[DataCite 公共接口的记录范围](https://support.datacite.org/docs/rest-api)。
