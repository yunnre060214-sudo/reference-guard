# 参考文献纠错

唯一目的：参考文献真实存在，文末参考文献的信息与格式正确。适用于写作过程中生成文献表、核查已有论文，以及补充或整理参考文献。只处理参考文献部分；正文写法、如何引用、论断是否得到文献支持均交给论文撰写流程。

## 执行

1. **确定格式。** 用户已明确指定格式或提供适用模板时按其要求执行。没有明确要求时先询问；只有用户明确表示没有格式要求，才使用 **GB/T 7714—2025**。未答复不等于没有要求。格式未定时可先核查真实性。
2. **先取得来源记录。** 按 [真实性与信息核查](references/verification.md) 给每条原始文献保留稳定 ID、原文和字段证据。生成新条目也必须先检索真实记录。DOI 能打开、搜索结果相似、另一篇论文曾引用它，都不能单独证明该条引用正确。没有 DOI 的文献照常核查。
3. **修正并生成文献表。** 有证据且作品身份明确的字段直接修正；题名、作者、DOI 等指向不同作品，进一步核查仍无法确定身份时，询问用户，保留该条待确认。按 [格式输出](references/formatting.md) 生成候选修正版；信息未知时如实记录，不补造作者、题名、日期、卷期页码或标识符。
4. **强制独立对抗复核。** 交付前必须实际创建子代理，依 [复核协议](references/adversarial-review.md) **逐条独立复核全部原始条目与候选修正版**，包括暂未修复的条目。给它原始材料、候选结果、目标规范；主代理的通过结论和核验台账不作为复核答案。记录真实代理标识、独立查阅来源及逐条结果。自查、角色扮演、抽查、单纯运行脚本不能代替这一步。
5. **修复、再复核、冻结。** 有证据支持的复核问题由主代理修正，修正后重新复核当前完整版本。没有新证据或需要用户选择时保留明确的未解决状态。通过后原样交付已复核内容；任何后续改写都要重新复核。可用 `scripts/review_gate.py` 检查覆盖、版本摘要及阻断问题；它只检查结构，不证明来源真实或代理确实创建。

## 交付契约

- **问题与修正说明：** 原条目 ID、实际问题、修正依据及来源链接。格式问题与作品/字段错配分开写。
- **修正后的参考文献：** 只收录真实性、实际输出字段和目标格式均已核实，且独立复核通过的条目。证据链接和核查注释放在说明中，保持文献表符合目标格式。
- **未解决条目：** 保留原条目，说明查过的来源、无法确定之处及需要的材料或关键问题。检索不到不能直接断言文献不存在。
- **复核结果：** 实际审查条数、交付条数、未解决条数、复核代理与结果。仅部分条目完成时明确写“部分已核实”；没有完成真实子代理复核或格式规范不可核实时，写明未完成，不能宣称交付的是已全部核验的正确版本。

任务没有明确授权修改原文件时，交付修正版及说明。已有写作流程继续负责正文；本 skill 不擅自选择另一篇作品、不评价应引用哪一版本，也不修正文内引文编号。
